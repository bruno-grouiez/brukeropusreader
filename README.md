# Bruker OPUS Reader

## Introduction

`brukeropusreader` is a Python package for reading binary OPUS files generated by Bruker spectrometers.

This repository is a fork of the original [brukeropusreader project](https://github.com/qedsoftware/brukeropusreader). It retains the original functionality and adds extensions for EM27/SUN data processing.

## Features

- Read binary OPUS files and access their parsed data through an `OpusData` object.
- Support additional EM27/SUN detector blocks, including `IgSm2` and `ScSm2` where present in the OPUS file.
- Read selected OPUS blocks with `read_blocks()` instead of parsing the entire file.
- Access spectral ranges and interpolate spectral data using the provided methods.

See [FORK_NOTES.md](FORK_NOTES.md) for details about fork-specific changes, usage examples, performance measurements, and validation status.

## Installation

### Requirements

- Python 3.13 has been tested.
- NumPy
- SciPy

Other Python versions have not been systematically tested.

### Install from this repository

Clone the repository and switch to the recommended `main` branch:

```bash
git clone https://github.com/bruno-grouiez/brukeropusreader.git
cd brukeropusreader
git switch main
```

Create and activate a virtual environment:

```bash
python -m venv .venv
```

On Linux:

```bash
source .venv/bin/activate
```

On Windows:

```powershell
.venv\Scripts\activate
```

Install the package and its dependencies:

```bash
python -m pip install --upgrade pip
python -m pip install -e .
```

### Install from PyPI

```bash
pip install brukeropusreader
```

**Note:** The PyPI release may not include the fork-specific extensions documented in `FORK_NOTES.md`. Install from this repository if you need those features.

## Usage

### Read an OPUS file

The `read_file()` function parses an OPUS file and returns an `OpusData` object.

```python
from brukeropusreader import read_file

opus_data = read_file("opus_file.0")

print("Parsed fields:", list(opus_data.keys()))
```

For example, to access a field returned by the parser:

```python
print(opus_data["AB"])
```

The available fields depend on the contents of the OPUS file.

### Read selected blocks

The `read_blocks()` function allows you to parse only the blocks you need.

```python
from brukeropusreader import read_blocks

opus_data = read_blocks(
    "opus_file.0",
    ["IgSm Data Parameter"],
)

print(opus_data["IgSm Data Parameter"])
```

This can reduce unnecessary parsing when working with large OPUS files or when only a subset of the available information is required.

### Access and interpolate spectral data

The `OpusData` object provides methods to access spectral ranges and interpolate spectral data. For example:

```python
spectrum_range = opus_data.get_range("ScSm")
print(spectrum_range)
```

See [FORK_NOTES.md](FORK_NOTES.md) and [example.py](example.py) for additional examples and details about the available methods.
